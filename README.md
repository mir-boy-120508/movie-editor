# Web動画編集(ブラウザ完結型)

4K動画を読み込み、カット・結合・テロップ・BGMを編集して、FHD(1920×1080)で書き出せる、ブラウザだけで動くシンプルな動画編集サイトです。サーバーは使わず、GitHub Pagesにそのまま置くだけで動きます。

## 使い方(自分のパソコンで試す)

ブラウザの制約上、`index.html` をダブルクリックするだけでは動きません(ローカルサーバー経由で開く必要があります)。

1. このフォルダをターミナルで開く
2. 以下のいずれかを実行してローカルサーバーを立てる
   - Python がある場合: `python3 -m http.server 8000`
   - Node.js がある場合: `npx serve .`
3. ブラウザで `http://localhost:8000` を開く

## GitHub Pagesへの公開方法

1. GitHubで新しいリポジトリを作成する
2. このフォルダの中身(`index.html`, `css/`, `js/`, `coi-serviceworker.js` など)をそのままリポジトリにアップロードする
   - GitHubのWeb画面から "Add file" → "Upload files" でドラッグ&ドロップでもOKです
3. リポジトリの **Settings → Pages** を開く
4. "Build and deployment" の "Source" を **Deploy from a branch** にする
5. Branch を `main`(または該当のブランチ)、フォルダを `/ (root)` にして Save
6. 数分待つと `https://ユーザー名.github.io/リポジトリ名/` でサイトが公開されます

ビルド作業(npm installやnpm run buildなど)は一切不要です。ファイルをそのまま置くだけで動きます。

## 機能

- 動画ファイルの読み込み(4K対応、複数ファイル可)
- タイムライン上でのカット(分割)・トリム(端をドラッグして長さ調整)・並べ替え
- テロップ(テキスト)の追加、表示時間・位置・色・サイズの調整
- BGMの追加(元動画の音声とミックスされます)
- プレビュー再生
- FHD(1920×1080)での書き出し(ブラウザ内でffmpeg.wasmを使用)

## 技術的な仕組み・注意点

- **すべてブラウザ内で処理**しています。動画はどこにもアップロードされません。
- 書き出しには `ffmpeg.wasm` を使っています。初回書き出し時にライブラリ(数十MB)をCDNから読み込むため、少し時間がかかります。
- マルチスレッド処理を有効にするため `coi-serviceworker.js` を使ってCOOP/COEPヘッダーを疑似的に付与しています。**初回アクセス時に自動でページが1回リロードされます**(正常な動作です)。
- 4K素材をそのままプレビューすると重いため、現状はブラウザの動画デコード性能に依存しています。素材が長い・重いとプレビューがカクつくことがあります。
- 書き出し処理は素材の長さ・本数に比例して時間がかかります(数分かかることがあります)。ブラウザのタブを閉じないでください。
- BGMは元動画の音声と**ミックス**されます(音声を置き換えるのではなく重ねる仕様です)。
- 対応ブラウザ: 最新版の Chrome / Edge を推奨します(SharedArrayBufferとWebCodecs関連の機能を使うため)。
